# Maison Rouge Archive

A luxurious art-deco PWA for saving prompts, outputs, and persona-based responses.

## Files

- `index.html` — app shell
- `manifest.webmanifest` — PWA manifest
- `sw.js` — service worker for offline cache
- `icons/icon.svg` — app icon

## Deploy

This repository is ready for GitHub Pages or Cloudflare Pages. Set the publish directory to the repository root.
